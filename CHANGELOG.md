# Changelog

All notable changes to the independently developed premium-style extension are documented here.

## 1.0.0 — 2026-07-21

### Added

- Persistent brand identity systems with strategy, voice, visual direction, and semantic tokens.
- Production token exports for CSS, Tailwind, TypeScript, and JSON.
- Executed AI image generation with provider abstraction, saved assets, retries, hashes, and provenance manifests.
- Editable SVG logo systems and custom icon families with validation.
- Corporate identity collateral and coordinated banner-family exports.
- Presentation-system guidance, layouts, chart rules, outlines, and generation prompts.
- Enterprise parent/child/product token inheritance, overrides, versioning, migrations, and governance metadata.
- Brand consistency auditing and complete-package workflows.
- CI coverage for source/mirror parity, regression tests, browser smoke tests, and extension-specific workflows.

### Compatibility

- Built as an independent extension of the MIT-licensed UI UX Pro Max repository.
- Existing free-skill search and design-system behavior remains available.
- Paid image generation occurs only through an explicit render command and configured provider credentials.
